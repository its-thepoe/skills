# @its-thepoe/copywriting

**Agent Skill** for unified marketing copy, product UX writing, error messages, and
voice/tone systems.

Use `surface:marketing` for public conversion copy, `surface:product` for in-product
flows and states, or `surface:both` to align the whole product experience.

Install:

```bash
npx @its-thepoe/skills@latest install copywriting
```
