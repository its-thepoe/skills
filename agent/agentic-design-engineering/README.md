# @its-thepoe/agentic-design-engineering

**Agent Skill** for adaptive multi-agent product design and engineering workflows:
`Specify -> Plan/Design -> Build -> Critique -> Fix -> Verify`.

It keeps small tasks lightweight while adding independent review, structured
handoffs, and evidence-based verification to larger or higher-risk work.

## Install

```bash
npx @its-thepoe/skills@latest install agentic-design-engineering
```
